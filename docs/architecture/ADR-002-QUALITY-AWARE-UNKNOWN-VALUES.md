# ADR-002：显式 Unknown 与质量感知统计

- 状态：Accepted
- 日期：2026-10-13

## 背景

微信本地数据可能存在字段缺失、版本漂移、分片缺失、时间不完整和重复记录。如果把未知值转换成 0 或最相似枚举，界面会产生可信但错误的统计。

## 决策

所有 canonical event 和聚合结果必须显式表达未知、覆盖和质量。

### 规则

- 枚举未知使用 `unknown`；
- 数值或时间没有可靠来源使用 `null`；
- `0` 只表示可靠的零；
- 覆盖和质量分离；
- 聚合结果携带 `DataQuality`；
- 时光墙返回稠密日期序列；
- 无记录、无覆盖、解析失败使用不同状态；
- UI 洞察受质量门控；
- 推断值必须标注 confidence 或 quality flag。

## 统计集合

```text
E：所有去重后的通话尝试
C：可靠确认已接通的事件，C ⊆ E
D：具有可靠接通时长的事件，D ⊆ C
```

- 尝试次数使用 `|E|`；
- 接通次数使用 `|C|`；
- 总时长、平均、中位和最长只使用 `D`；
- UI 必须显示相关分母或在说明中可查。

## 覆盖与质量

Coverage 回答“哪些时间和来源被检查”；Quality 回答“已经取得的数据是否可靠”。

禁止用解析成功率冒充完整历史覆盖，也禁止在没有外部真值时使用“准确率 97%”之类表述。

## 后果

- UI 会出现 Unknown、Partial 和 Missing 等状态；
- 数据模型比简单记录更复杂；
- 某些指标在质量不足时必须隐藏；
- 用户不会因缺失数据得到过度自信的结论；
- 新微信版本可安全降级，而不是静默误解析。
