## 安全验证

- 进程权限仅 `PROCESS_QUERY_INFORMATION | PROCESS_VM_READ`；
- 无 DLL 注入、Hook、进程写入、Shell 或网络权限；
- 微信原库不以写模式打开；
- 数据库密钥不落盘、不经 IPC 返回前端；
- 进程扫描块、候选密钥和派生密钥使用后清零；
- 扫描有互斥、90 秒、4 GiB 扫描量和 512 候选预算；
- 未验证微信 build 会拒绝自动读取；
- WAL 无法完整验证时回退主库并标记 partial，而不是声称完整；
- 临时明文快照正常结束后删除，应用启动和扫描前清理陈旧快照；
- 脱敏导出重新随机映射账号、联系人、事件、会话和来源 ID。

## 已知限制

- 当前自动扫描仅支持 Windows 微信 4.1.15.13；
- 扫描尚未按正式 API Contract 拆为 start/status/cancel/progress；
- 本地规范化 `dataset.json` 尚未加密；
- 强制结束进程或断电时无法保证即时删除临时明文；后续启动会清理；
- 尚无代码签名证书，SmartScreen 可能提示未知发布者；
- macOS、增量扫描和更多微信版本尚未支持。
