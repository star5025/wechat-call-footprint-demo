# 通话足迹 v0.3 · 时光墙 UI Demo

双击 `index.html` 即可体验。

## 这版新增

- 独立“时光墙”页面，视觉参考 GitHub Contribution Graph
- 支持按一年、一个月和自定义时间段展示
- 颜色深浅表示每日通话时长
- 展示活跃日、通话次数、总时长和最亮的一天
- 悬停格子查看摘要，点击日期查看当天记录
- 可切换 2025/2026 年和月份
- 自定义范围最多 366 天

## 原有体验

- 消费级轻松界面：首页、时光墙、小发现、通话记录
- 柔和渐变、大卡片、圆润图形和轻量操作
- 联系人隐私模式、通话筛选与详情抽屉

## 说明

仍然只使用本地模拟数据，不读取真实微信数据库。时光墙中的历史日期包含用于展示效果的模拟聚合数据，近期通话日使用 Demo 的逐条记录。
